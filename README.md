An AI-powered web application that helps users discover food and restaurant suggestions based on their cravings, mood, or preferences.

---

## 🚀 Features

- 🔍 **AI-Based Food Recommendation**
  - Enter your craving (e.g., "spicy food", "dessert", "healthy meal")
  - Get intelligent dish suggestions

- 🖼️ **Interactive Food Cards**
  - Click on any food item to view detailed information
  - Clean and modern UI with smooth interactions

- 📋 **Booking System**
  - Book your selected food item
  - Simple form to collect user details (Name, Phone, Address)

- ⚡ **Dynamic UI**
  - Modal-based popups for better user experience
  - Responsive design for mobile and desktop

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Concepts Used:**  
  - DOM Manipulation  
  - Event Handling  
  - Modal UI Design  
  - Prompt-based AI logic  

---

## 💡 How It Works

1. User enters their food preference or craving  
2. System generates a relevant food suggestion  
3. User clicks on a food item  
4. Detailed view opens with description  
5. User can book the item using a simple form
